# sto/

The **Structural Trustworthiness Ontology (STO)**, a standalone, versioned
standard that may be cited and used independently of the benchmark.

- `STO-<version>.json` — the normative class register (identifiers, definitions,
  scope, inclusion and exclusion criteria, examples, counterexamples,
  relationships, and gold type per class).
- `schema/sto.schema.json` — the schema the register validates against.

Class identifiers are permanent; incompatible redefinition requires a new
identifier and deprecation of the old (see `GOVERNANCE.md`). The ontology is
populated in the STO work package.
